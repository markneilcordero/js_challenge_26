### **CodeBreaker**

### **Welcome!**  
Think you have what it takes to crack the code? In **CodeBreaker**, a secret 4-digit code has been randomly generated, and it’s your mission to figure it out! You have 12 attempts to guess the correct combination—are you up for the challenge?

---

### **What to Expect**  
- **Random Code Generation:** The computer creates a random 4-digit code.  
- **Smart Guess Validation:** Your guess must be exactly 4 digits—no more, no less!  
- **Feedback System:** After each guess, you'll get clues:
  - How many digits are in the correct position.
  - How many digits are correct but in the wrong position.
- **Winning Condition:** Crack the code within 12 attempts to win!  
- **Losing Condition:** If you run out of guesses, the game ends, and the secret code is revealed.

---

### **How to Play**  
1. **Install Node.js:**  
   If you don’t have Node.js installed, download it here: [https://nodejs.org/](https://nodejs.org/).

2. **Install Dependencies:**  
   In your terminal, run:
   ```bash
   npm install prompt-sync
   ```

3. **Run the Game:**  
   Save the script as `index.js` and start the game:
   ```bash
   node index.js
   ```
